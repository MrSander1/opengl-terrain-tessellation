# Procedural Terrain Generation with OpenGL in C++ (Tessellation) 
A 3D procedural terrain generator built using OpenGL and C++. This project is similar to my previous terrain generator, though the notable differences mainly lie in the inclusion of tessellation to improve optimization. Other than that, there is also optional fog and grass. Additionally, more advanced controls are included for all current and previous features.
